# Days Since Last Heat Scrim Website
Pretty self explanatory, I'd say. 
# Features:
## Dynamic Images
Images change depending on the days since the last heat scrim.
- 28+ days: Hiroshima Nuke
- 21+ days: Graveyard
- 14+ days: dried plant
- Anything else: Guy doing thumbs up :)
## Live Timer
Live timer that uses Unix Epoch time to find the time difference. Updates every second.

> Note: This project probably won't get updated very often. Maybe once a month at best. It was fun while it lasted.
